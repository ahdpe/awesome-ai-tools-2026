## [2026-10-18] Catalog review

### Added

- Coding: Google Antigravity, OpenCode.
- Agents & automation: Claude Agent SDK, n8n.
- RAG & search: Exa, Tavily.
- Evaluation: Braintrust.
- Image: Gemini Image (Nano Banana), GPT Image.
- Audio: AssemblyAI.
- Platforms: Google Vertex AI, Amazon Bedrock, DeepSeek API.

### Changed

- Microsoft AutoGen replaced by its successor, Microsoft Agent Framework; AutoGen is in maintenance mode.
- Mistral AI La Plateforme renamed to Mistral AI Studio.
- Claude Code and Anthropic API links moved to `code.claude.com` and `platform.claude.com`; the Claude Code description now covers IDE, desktop, and web.
- FLUX links to `bfl.ai` and describes the FLUX.2 lineup.
- Invoke relabeled as a community-maintained open-source project after its hosted service closed.
- Aider and W&B Weave descriptions note slowed development and CoreWeave ownership.
- Windsurf replaced by Devin Desktop after the rebrand.

### Removed

- Sora: the app closed in April 2026 and the API in September 2026.
- Roo Code: the extension, cloud, and router were discontinued in May 2026.
- Continue: acquired by Cursor; the repository has been read-only since June 2026.
- Udio: downloads were disabled after the label settlements, and the licensed relaunch is a closed platform.
